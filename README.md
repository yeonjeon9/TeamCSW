### 🌱 우리 팀의 규칙

### 1. **소통 규칙**

- **서로의 말을 경청**하고 중간에 끼어들지 않기
- **피드백은 빠르고 구체적으로**, 비난이 아닌 개선의 방향으로 전달
- 하고 싶은 말이 있다면 **돌려 말하지 않고 솔직하게 표현**하기 (하지만 말투는 배려 있게)
- 불편한 상황이나 감정은 **바로 이야기하거나, 안전하게 말할 수 있는 시간/공간을 마련**하기

### 2. **업무 수행 방식**

- **기한과 역할을 명확히 정하기** (예: 이번 주 안에 누구는 어떤 부분을 어디까지)
- 일정, 회의 시간은 **사전에 확정하고, 시간 약속을 반드시 지키기 (시작, 마감 모두)**
- 2시간 이상 지속되는 회의는 **피로도 고려해 휴식 포함 or 분할**
- 팀 회의 시, **카톡이나 핸드폰 사용 자제** (집중도 저하 방지)

### 3. **업무 환경**

- 몰입이 필요한 작업 시간에는 **조용한 환경을 보장** (배경음악 무, 백색소음 가능)
- **화이트보드/아이패드 등 시각적 도구 적극 사용**
- 음악 최대한 자제
- 수업이 하나만 있는 날은 점심시간 30분

### 4. **정서적 안정**

- 서로의 감정을 존중하며, **비난·무시·인격적 모독 금지**
- **욕설이나 거친 말투 사용 금지**, 유쾌하고 따뜻한 분위기 지향
- 힘든 일이 있거나 체력이 부족할 땐 **솔직하게 공유하고 무리하지 않기**
- **칭찬과 격려는 자주, 진심을 담아** 전달

### 5. **건강과 리듬 존중**

- 잠과 밥은 개인 리듬에 따라 **존중하되, 일정에는 영향 없도록 조정**
- **개인감정 or 기분으로 업무에 지장 주지 않기**, 기분 좋지 않을 땐 사전 공유

### 6. **우리 팀의 분위기**

- **안정적이고 안전한 분위기**: 누구든 자기 생각과 감정을 부담 없이 이야기할 수 있는 팀
- **라포 형성 중심**: 감정 교류와 웃음을 함께하며 즐겁게 일하기
- **실패를 두려워하지 않는 도전의 문화**: 아이디어는 자유롭게, 실행은 함께
